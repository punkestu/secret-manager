# Secret Manager
Just made it to store encrypted password

## How to use it?
1. Clone
2. Create config directory ```$HOME/.config/secret-man/```
3. Set env for (or leave it empty if you are lazy like me)
    - PERSONALSECRET_CAESAR_SHIFT
    - PERSONALSECRET_PROCESSOR
    - PERSONALSECRET_SQLITE_FILEPATH
4. Run index.js and do everything you want I don't care.
